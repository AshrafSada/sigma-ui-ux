# SIGMA UI/UX Designer

This is a new basic free UI/UX designer, inspired by Figma.

## Technologies

React Next JS is the main App framework for React and the Web, additional dependecies are:
    - Live Blocks (public API Key): Realtime infrastructure for multiplayer apps and agents.
    - Next Js: The React Framework for the Web
    - Tailwind CSS: A utility-first CSS framework for rapid UI development.
    - Fabric Js: A simple and powerful Javascript HTML5 canvas library.
    - UUId: A universal unique id generator.

### NPM Dependencies

The listed packages are required as dependecies, and must be installed from NPM:

    - @liveblocks/client
    - @liveblocks/react
    - @tailwindcss/postcss
    - uuid
    - fabric

## Deleopment Tools

In this project we are using windows 11, with power shell, vs code.
